# קונטקסט ארגוני לסוכנים

כאן שמים את מקורות הידע שהסוכנים קוראים. **איכות הסוכנים תלויה באיכות הקבצים האלה.** בעלי הקבצים הם האנליסטים וה‑PO.

| קובץ | משמש את | תוכן |
|------|---------|------|
| `strategy.md` | מגבש דרישה | יעדים, OKR ועדיפויות |
| `services-catalog.md` | שירותים/דאטה | שירותים, צוותים בעלים, ממשקים |
| `design-system.md` | UI/UX | רכיבים, הנחיות ונגישות |
| `estimation-history.csv` | מתמחר | `task,component,estimated_days,actual_days,team,date` |
| `rates.md` | מתמחר | תעריף יומי לפי משאב |
| `capacity.md` | לו"ז | צוותים, זמינות, חופשות וחגים |

אפשר להחליף קבצים בחיבורי MCP (Jira, Confluence, Figma, DB לקריאה בלבד).
