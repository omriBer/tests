The "React + Vercel" Extreme Transformation Prompt
Goal: Rebuild the entire application as a high-end, mobile-first Next.js/React web app. The UI must be a Tinder-style "Workout Matcher" for Couch Potatoes, abandoning the outdated Streamlit look.

1. Tech Stack & Deployment:

Framework: Next.js (App Router), Tailwind CSS, Framer Motion (for animations).

Vercel Ready: Ensure the project structure is optimized for Vercel deployment (e.g., package.json, next.config.js).

PWA Support: Implement a manifest.json and service worker so the user can "Add to Home Screen" on iPhone/Android and view it in full-screen.

2. Visual Revolution (The "Tinder" Look):

Aesthetic: Dark Glassmorphism. Deep black backgrounds (#0D1117), frosted-glass cards (rgba(22, 27, 34, 0.7) with blur-lg), and Neon Green (#00E676) action accents.

The Matcher (Home Screen): A vertical stack of large, tactile Image Cards.

Contexts: 🍿 Microwave Hero, 💻 Zoom-Proof Core, 👶 Kid-Toss Cardio, 🍕 Post-Meal Burn.

Gear: ✋ Just Me, 🎒 Basic Gear.

The Muscle Map: A central, interactive SVG body map (ported from muscles.py). Touching a muscle must trigger a neon-glow effect and start the workout instantly.

3. The Hero Workout Player:

Layout: Full-screen mode. The Looping GIF must be the hero, occupying 80-90% of the screen.

Overlays: * A sleek, circular neon progress timer at the top.

Floating badges at the bottom: ✅ DO: [Tip] and ❌ X: [Mistake].

Zero-Friction: Log workouts automatically in the background after the 4-minute circuit ends. No post-workout forms.

4. Intelligence & Vibe Logic:

Garmin-Driven UI: Silently sync with Garmin data (Body Battery). If BB is <40, make the "Couch Potato" (Easy) card pulse with a subtle glow.

Ghost Coach: Repurpose coach.py logic. The coach appears only as a celebratory toast/overlay after a workout to show streaks or "Weekly Insights."

5. Implementation Steps:

Setup the Next.js project with Tailwind.

Build the Selection Matrix (Context/Gear/Muscle).

Build the Workout Player with a 60-second timer per step.

Integrate the existing exercises_db.json for the workout generation logic (1x Warmup, 2x Effort, 1x Stretch).
